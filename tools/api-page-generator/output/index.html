Prompt

https://stride-tasks.github.io/stride/api/notification/stride.user.prompt.schema.json

A prompt is a message or question that is presented to the user, often as part of an interactive system or application, and it may also include actions that the user can take in response to the prompt.

Field Type Required Description
summary string yes A brief summary of the prompt.
description string no A detailed description of the prompt.
target UserPromptTarget yes target
actions array<string> yes A list of actions that the user can take in response to the prompt.
